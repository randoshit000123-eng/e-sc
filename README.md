# E-Scooter Elytra (Fabric, Client-only, Minecraft 1.21.4)

Trägst du eine Elytra in der Brustplatte-Slot, fährst du als E-Scooter-Fahrer (Räder drehen mit,
Lenker schlägt mit dem Kopf ein, Oberkörper lehnt sich in die Fahrt). Beim Gleiten bleibt die normale Elytra.

Eingebautes Resource Pack "E-Scooter Pack" (automatisch aktiv): Hotbar-/Slot-Design, Elytra-Icon, Name "E-Scooter".

## Bauen
Java 21 nötig:  `./gradlew build`  ->  `build/libs/escooter-1.0.0.jar`
Zusätzlich Fabric Loader >= 0.16 und Fabric API für 1.21.4 in den mods-Ordner.
(Oder Projekt auf GitHub pushen: der Workflow baut die Jar als Artifact.)
